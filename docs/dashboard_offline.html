    How the model works

    Functional unit: one use of one panel at one exhibition event. All burdens of a panel's life are spread over the expected number of uses: per use = (production + Σ per-event burdens + end of life − credit) / expected uses.

    Expected uses follow geometric survival: E[uses] = Σk=0..N−1(1−p)k, where p combines handling damage (not repaired) and the chance a panel is not redeployed.

    Credit: net scrap credits only recovered metal beyond the recycled input share, valued at (EF primary − EF secondary), which avoids counting recycled content twice. Cut-off gives no credit.

    Circularity is a simplified Ellen MacArthur Material Circularity Indicator with utility = expected uses. Score = weighted sum of min–max scaled climate and cost plus circularity and feasibility.

    This page is a JavaScript port of src/cirdesign (model.py, recommend.py, analysis.py) and reproduces the Python results exactly. Monte Carlo uses its own random generator, so individual draws differ from Python's. The Python project also trains a Random Forest surrogate of this model; it is left out here because the model itself runs in milliseconds in the browser, so a learned imitation adds nothing.
